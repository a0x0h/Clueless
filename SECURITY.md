# Security

Clueless runs locally. It listens on `localhost:47321` only (for the Chrome extension), transcribes your mic with a local Whisper server bound to `127.0.0.1`, and sends text and screenshots only to the Claude desktop app, when you ask.

If you find a security problem, please report it privately through GitHub's **Report a vulnerability** button on the Security tab, not in a public issue.
